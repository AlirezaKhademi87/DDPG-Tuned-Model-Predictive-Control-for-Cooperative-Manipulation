# MATLAB Code for Figures 4-9

This repository contains the MATLAB code used to reproduce Figures 4-9 of the manuscript.

## Quick start — which file should I run?

**Run only:**

```matlab
run_all
```

`run_all.m` is the main entry point. No other MATLAB file needs to be run manually.

When `run_all.m` is executed, it performs the following steps:

1. Adds all required subfolders to the MATLAB path.
2. Looks for the two precomputed result files in the `results/` folder:
   - `Result_MPC_Fixed_Disturbed.mat`
   - `Result_DDPG_MPC_Disturbed.mat`
3. If both MAT files are present, they are loaded directly so the figures can be reproduced immediately.
4. If either MAT file is missing, the corresponding simulation is run automatically and the missing MAT file is recreated.
5. Only Figures 4-9 of the manuscript are generated.

The code requires MATLAB Optimization Toolbox because the MPC optimization uses `fmincon`.

## Precomputed MAT files

The `results/` folder contains the two result files used for the manuscript figures. These files are **outputs of the simulation code**, not external input data.

- `Result_MPC_Fixed_Disturbed.mat` is generated by the fixed-gain MPC case.
- `Result_DDPG_MPC_Disturbed.mat` is generated by the adaptive-weight case.

The MAT files are included to allow rapid reproduction of the figures without rerunning the optimization. They can be deleted safely: running `run_all.m` will recreate them from the MATLAB source code.

The same fixed disturbance realization is used in both cases (`rng(10)`) to provide a consistent comparison.

## Code organization

The original integrated simulation was divided into smaller files so that the model, controller, adaptive tuning, simulation loop, and plotting routines can be inspected independently.

- `run_all.m` — main entry point; this is the file to run.
- `simulation_parameters.m` — robot, object, MPC, and simulation parameters.
- `build_reference_trajectory.m` — object and gripper reference paths.
- `run_simulation_case.m` — rolling-horizon simulation loop.
- `save_case_result.m` / `load_results.m` — result-file handling.
- `controller/` — MPC cost, constraints, adaptive weight update, reward, and related controller functions.
- `model/` — forward/inverse kinematics, Jacobian, gravity model, and disturbance generation.
- `utils/` — small numerical helper functions.
- `plotting/` — functions used to reproduce Figures 4-9.
- `results/` — precomputed simulation outputs used for immediate figure reproduction.

## Relation between the simulations and MAT files

The two MAT files are generated from the same simulation framework. The fixed-gain case is run with adaptive tuning disabled, while the adaptive case is run with adaptive tuning enabled. Therefore, the workflow is:

```text
MATLAB simulation code
        |
        +-- Fixed-gain MPC --------> Result_MPC_Fixed_Disturbed.mat
        |
        +-- Adaptive-weight MPC ---> Result_DDPG_MPC_Disturbed.mat
                                      |
                                      v
                                Figures 4-9
```

The result filename `Result_DDPG_MPC_Disturbed.mat` is retained for compatibility with the manuscript and the original post-processing workflow. In the released reproduction code, the supervisory layer applies state-dependent adaptive MPC-weight tuning during the simulation; online actor-critic training is not performed during reproduction of the reported figures.

## Figures 12 and 13

Figures 12 and 13 are based on experiments performed using the physical robotic system. Reproducing these results requires access to the actual robot hardware and the corresponding experimental setup. Therefore, the codes associated with these figures have not been included in this repository.
